## ✨ Features

**Visual Building**
- Drag & drop blocks to reorder
- Real-time preview with GitHub styling
- No markdown syntax required

**Content Elements**
- Structure: Titles, headings, sections
- Text: Paragraphs with formatting (bold, italic, code)
- Lists: Bullet lists and todo checklists
- Media: Images with size control and badges
- Code: Syntax-highlighted blocks
- Advanced: Tables, collapsible sections, quotes, links, dividers

**Alignment Control**
- Position every element left, center, or right
- Visual alignment buttons on each block
- Works for text, images, tables, badges, and more

**Smart Tables**
- Quick templates (2×2, 3×3, 4×4, 5×5)
- Direct markdown editing
- Custom dimensions up to 20×20

**Templates**
- Export your README as JSON template
- Import templates to restore complete layouts
- Share and reuse designs

**Export Options**
- Download as README.md
- Copy markdown to clipboard
- One-click export

## 🎨 Interface

**Dark Theme**  
Comfortable on the eyes with evergreen and cream tones

**Three-Column Layout**
- Sidebar: All content tools organized by category
- Editor: Build your README with live blocks
- Preview: See your README rendered as GitHub shows it

**Mobile Responsive**  
Works seamlessly on desktop, tablet, and mobile devices
